# Pavel Mareš

I have over 15 years of experience in industrial manufacturing — quality control, measurement, defect logging, and control panel operation in a powder coating plant. I am a trained electronics mechanic (vocational apprenticeship). In 2024 I completed a Junior Tester course (Engeto). I am interested in technical work in manufacturing as well as a junior role in IT, testing, or customer support.

## What I am doing now

From my phone, I direct the development workflow: an AI agent executes tasks on a separate computer. I prepare written specifications and verify results using automated tests that run automatically; AI creates both the code and the tests.

## Selected projects

- **[agora-pro-setup](https://github.com/painter99/agora-pro-setup)** — an unofficial governance and configuration layer for the Agora AI agent (F-Droid): prompt templates, Active Memory guidance, Skills, and operational documentation.
- **[cad-workshop](https://github.com/painter99/cad-workshop)** — a headless CAD framework: models are built from a text specification, their dimensions are verified by automated tests, and the output is a generated dimensioned drawing.
- **[wsw-olomouc](https://github.com/painter99/wsw-olomouc)** — an Android widget showing the current temperature from Olomouc weather stations; developed with the Agora AI agent, changes go through automated tests and CI, and I verify the result on a real phone.
